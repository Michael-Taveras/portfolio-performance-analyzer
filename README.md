# Portfolio Performance Analyzer

A C++ command-line program that analyzes the performance of a user-defined investment portfolio.

## Features

- Accepts multiple investments with their original and current values
- Calculates profit or loss for each investment
- Calculates percentage return for each investment
- Classifies each investment as a gain, loss, or no change
- Calculates total invested value and current portfolio value
- Calculates total portfolio profit/loss and return
- Identifies the best-performing investment

## Technologies and Concepts

- C++
- Functions
- Vectors
- Loops
- STL algorithms
- User input and input validation

## How It Works

The user enters the number of investments in their portfolio. For each investment, the program asks for:

1. Investment name
2. Original invested amount
3. Current value

The program then generates an individual performance report for each investment and a summary of the entire portfolio.
